API Documentation

Integrate Kiro AI with your local development environment using OpenAI-compatible endpoints.

Introduction

Kiro provides an OpenAI-compatible REST API. You can use any OpenAI client library (Python, JS, Go) by pointing the base_url to your Kiro instance.

Base URL

/v1

Authentication

Requests are currently authenticated via your existing dashboard session. No additional API keys are required for local access.

GET List Models

Retrieves a list of all models available through your connected AWS CodeWhisperer accounts.

Endpoint /v1/models
curl /v1/models

POST Chat Completions

Generate responses from your selected AI models using a familiar chat-completion interface.

Request Body

{ "model": "claude-3-5-sonnet-20241022", "messages": [{"role": "user", "content": "Hi"}], "stream": false }
curl /v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "claude-3-5-sonnet-20241022", "messages": [{"role": "user", "content": "Hello"}] }'

POST Anthropic Messages

Use the native Anthropic protocol format. Ideal for tools strictly requiring the Claude Messages API.

Request Body

{ "model": "claude-3-5-sonnet-20241022", "max_tokens": 1024, "messages": [{"role": "user", "content": "Hello"}], "stream": false }
curl /v1/messages \ -H "Content-Type: application/json" \ -H "x-api-key: sk-12345" \ -H "anthropic-version: 2023-06-01" \ -d '{ "model": "claude-3-5-sonnet-20241022", "max_tokens": 1024, "messages": [{"role": "user", "content": "Hello"}] }'

Integrations & CLI

Ready-to-use CLI commands to connect your favorite AI tools directly to Kiro.

Claude Code (Anthropic CLI)

Connect Anthropic's official claude CLI to Kiro. The CLI will communicate using Kiro's proxy URL and your configured models. Note: You must select an Anthropic model (like claude-3-5-sonnet-20241022-v2:0).

export ANTHROPIC_BASE_URL="" && \ export ANTHROPIC_AUTH_TOKEN="kiro-local-session" && \ export ANTHROPIC_API_KEY="kiro-local-session" && \ claude --model claude-sonnet-4.5

Global Prompt Template

Define custom tags that will be automatically replaced in your prompts. You can use these to add expert personas or predefined instructions.
